# 图提取 ImageGrab

一款 Chrome 浏览器扩展，用于在淘宝、京东、拼多多商家版的商品详情页一键提取所有商品图片，集中预览、自由勾选，并批量下载为统一 PNG 格式。

## 功能

- **一键提取**：扫描页面所有商品图，兼容懒加载（`data-src` / `data-lazy-src` / `srcset` / 背景图）
- **智能过滤**：自动排除图标、logo、占位图、1x1 像素图等干扰项
- **集中预览**：新标签页网格化展示所有图片，附带尺寸信息
- **自由勾选**：支持全选 / 反选 / 清空，实时显示已选数量
- **统一 PNG**：自动将 jpg / webp 等格式转换为 PNG
- **批量下载**：一键保存到浏览器默认下载目录，文件名自动编号（商品图_001.png）

## 安装步骤

1. 下载本项目压缩包并解压到本地文件夹（路径建议用纯英文）
2. 打开 Chrome，地址栏输入 `chrome://extensions` 并回车
3. 打开右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」，选择解压后的文件夹
5. 插件出现在列表中即安装成功

## 使用方法

1. 打开淘宝 / 天猫 / 京东 / 拼多多（含商家版）的任意商品详情页
2. 等待页面完全加载（图片懒加载需要滚动一下加载更多）
3. 点击页面右下角的「获取图片」按钮
4. 插件会自动打开结果页，展示所有提取到的图片
5. 勾选需要的图片，点击「下载选中」
6. 图片会以 PNG 格式保存到浏览器的默认下载目录

## 文件结构

```
imagegrab/
├── manifest.json        # 扩展配置（Manifest V3）
├── content.js           # 注入悬浮按钮 + 提取页面图片
├── content.css          # 按钮样式
├── background.js        # Service Worker：打开结果页 + 转 PNG 下载
├── gallery.html         # 结果展示页
├── gallery.css          # 结果页样式
├── gallery.js           # 结果页交互逻辑
└── docs/                # 插件官方宣传网站（静态页面）
    ├── index.html
    ├── css/style.css
    └── js/main.js
```

## 技术说明

- 基于 **Manifest V3** 规范开发
- 权限：`activeTab`、`scripting`、`downloads`、`storage`
- 跨域图片转 PNG 的处理放在 Service Worker 中进行：
  通过 `fetch` + `createImageBitmap` + `OffscreenCanvas` 转换，
  规避了在页面里使用 canvas 读取跨域图片导致画布被污染的问题
- 所有处理均在本地浏览器完成，图片不上传任何服务器
